### 0.2 8 维度参数说明

每设备按以下 8 维度描述（**维度顺序固定**，便于跨设备对比）：

1. **单元类型 / 数量**：动圈 / 动铁 / 静电 / 同轴 / 全频
2. **阻抗**：单位 Ω，注明测量频率（典型 @1kHz）
3. **灵敏度**：dB SPL/mW 或 dB SPL/Vrms，注明测试条件
4. **频响范围**：Hz - kHz，区分**标称**（厂家规格）与**实际**（-3dB/-10dB 边界）
5. **总谐波失真 THD**：%，注明测试条件（频率 / 声压级 / 输入功率）
6. **信噪比 SNR / 动态范围**：dB（部分品类 N/A）
7. **指向性 / 声学边界**：声场特征、单元物理上限、离轴响应、封闭/开放属性
8. **主观听感评价**：用户反馈的核心特征词 + 关键曲目表现

# 一、入耳式 IEM

## 1.1 IE900 复刻版

**品类**：入耳式 IEM | **核心架构**：复刻原版 Sennheiser IE900 的 7mm TrueResponse 动圈 + X3R 三腔体/三谐振器声学滤波结构；封闭式入耳。

### 关键声学参数

| 维度 | 数值 | 备注 | 来源 |
|---|---|---|---|
| 单元 | 7mm TrueResponse 动圈 | 单动圈 X3R 声学滤波 | 【官方】Sennheiser IE900 spec |
| 阻抗 | 32Ω（复刻常见，**非原版 18Ω**）| 复刻品参数浮动 | 【汇总】复刻品横向 |
| 灵敏度 | 约 96-99 dB SPL/mW | 复刻品浮动 | 【汇总】 |
| 频响 | 标称 2 Hz - 20 kHz | 实际高频延伸常受限 | 【官方】 |
| THD | 复刻品标称可达 **3%**（原版 <0.05%）| 失真差异显著 | 【汇总】复刻品对比 |
| SNR | N/A（IEM 无主动电路）| 被动单元 | — |
| 指向性 | 入耳式密闭，**离轴响应无意义** | 贴合耳道 | 【官方】 |

### 主观听感评价

- **腔体加工精度差**：复刻品腔体加工与原版存在差距，频响曲线一致性差，常见 6 kHz 附近陷波（"坑"）处理不当，导致中高频衔接不自然
- **低频调校风险**：Helmholtz 共振腔调校若不到位，容易出现低频"轰头"或浑浊，掩盖中频细节
- **失真特征**：3% THD 在中等音量下就可能产生可闻失真，**单元裕量小**

### 典型使用场景

- 通勤 + 办公桌前静听
- 复刻单元在低音量（< 60% 设备音量）下可听化原架构潜力

### 典型调音目标

- 6 kHz 中高频架桥补偿（修 6 kHz 陷波）
- 100-200 Hz 低频收敛（防轰头）
- 1-2 kHz 适度微调（人声密度）

## 1.2 BGVP Scale Pro

**品类**：入耳式 IEM | **核心架构**：10mm DC（钻石涂层）动圈 + 1 颗 HVEK 定制动铁混合；双音腔 + 电子+物理分频；封闭式入耳。

### 关键声学参数

| 维度 | 数值 | 备注 | 来源 |
|---|---|---|---|
| 单元 | 10mm DC 动圈 + 1 颗 HVEK 动铁 | 1 圈 1 铁 | 【官方】BGVP |
| 阻抗 | 17Ω（低阻抗）| 对前端输出阻抗极敏感 | 【官方】 |
| 灵敏度 | **113 dB SPL/mW**（极高灵敏度）| 易驱动 | 【官方】 |
| 频响 | 10 Hz - 40 kHz | 标称 | 【官方】 |
| THD | < 1% @ 1kHz | 标称 | 【官方】 |
| SNR | N/A（被动 IEM）| — | — |
| 指向性 | 密闭入耳 | 贴合耳道 | 【官方】 |

### 主观听感评价

- **底噪敏感**：极高灵敏度使其对前端底噪极敏感，前端若有底噪会被 113dB 灵敏度放大
- **分频点相位挑战**：动圈与动铁分频点通常落在中频段（2-3 kHz），此处若相位未对齐，会导致人声频段（200Hz-2kHz）的结像偏移
- **明亮不刺**：调音倾向"明亮不刺"，高频延伸但控制良好

### 典型使用场景

- 流行 / 人声 / 古典室内乐
- 需低输出阻抗前端（< 2Ω 输出阻抗最佳）

### 典型调音目标

- 2-3 kHz 分频点收敛（防结像偏移）
- 12.5-20 kHz 微抬（发挥 40kHz 延伸，Hi-Res 设备）
- 5 kHz 齿音下缘微抬（乐器存在感）

## 1.3 1圈14铁耳机（qdc Anole V14 参考）

**品类**：入耳式 IEM（多单元旗舰）| **核心架构**：1 个动圈 + 14 个动铁（含 EST 静电单元）的混合；4 分频（低/中/高/超高频）+ 4 独立声孔；Multitube 多路滤波专利抑制相邻频段串扰并补偿相位。

### 关键声学参数

| 维度 | 数值 | 备注 | 来源 |
|---|---|---|---|
| 单元 | 1 动圈 + 14 动铁（含 EST）| 4 分频 | 【官方】qdc Anole V14 |
| 阻抗 | 12-20Ω（极低）| 极敏 | 【官方】 |
| 灵敏度 | 105-108 dB SPL/mW（高灵敏度）| 易驱动 | 【官方】 |
| 频响 | 10 Hz - **50,000 Hz**（EST 拓展至 50kHz）| Hi-Res 标志 | 【官方】 |
| THD | 标称 < 1% | — | 【官方】 |
| SNR | N/A | 被动 | — |
| 指向性 | 密闭入耳 + 4 独立声孔 | 相位补偿 | 【官方】 |

### 主观听感评价

- **频响平直度与声道匹配优**：多单元分频设计通常 < 2dB 声道匹配
- **分频点相位核心挑战**：若 Multitube 调校不当，分频点附近（200-500 Hz 与 2-4 kHz）会产生相位抵消，导致"脱节"或结像模糊
- **动圈氛围 + 动铁密度**：低频靠动圈氛围，中高频靠多个动铁的密度与解析
- **EST 50kHz 延伸**：在线/本地无损下可听化超高频泛音与空间残响

### 典型使用场景

- 古典 / 爵士 / 原声 / 录音室监听
- 推荐 24bit/96kHz 以上 Hi-Res 内容
- 音量 ≤ 70%（底噪敏感）

### 典型调音目标

- 350 Hz / 3000 Hz 双分频点补偿
- 12.5-20 kHz +0.3dB（Hi-Res 内容释放，设备 hi_res_capable）
- 1k 轰头收敛（防多单元密度叠加）

# 二、头戴式耳机

## 2.1 头戴式开放式 — HD800

**品类**：头戴式 HP | **核心架构**：56mm 环形动圈（Ring Radiator）开放式；标志性斜置声波前障板模拟人耳耳廓自然声学反射以营造空间感。

### 关键声学参数

| 维度 | 数值 | 备注 | 来源 |
|---|---|---|---|
| 单元 | 56mm 环形动圈 | 开放背板 | 【官方】Sennheiser |
| 阻抗 | **300Ω**（@1kHz，110Hz 处有约 **650Ω 谐振峰**）| 极高阻抗 | 【官方】Sennheiser |
| 灵敏度 | **102 dB SPL**（@ 1kHz, 1Vrms）| 需驱动电压 | 【官方】Sennheiser |
| 频响 | 6 Hz - 51,000 Hz（-10 dB）| Hi-Res 旗舰规格 | 【官方】Sennheiser |
| THD | **≤ 0.02%**（@ 1kHz, 1Vrms）| 极低失真 | 【官方】Sennheiser |
| SNR | 极高（被动开放式，无主动电路噪声）| — | 【官方】 |
| 指向性 | 开放式（开放式背板辐射） | 几乎无隔音 | 【官方】 |

### 主观听感评价

- **声场规模**：源于开放式结构 + 单元斜置设计，宽阔通透
- **低频物理特性**：100 Hz 以下明显滚降（开放式动圈典型物理特性）
- **6-7 kHz 峰值**：导致高频"锐利"或"刺耳"感的声学根源
- **前端要求严苛**：300Ω + 110Hz 谐振峰对前端输出阻抗与驱动电压要求高

### 测量数据

- RTINGS / Crinacle 多次测量确认 6-7 kHz 抬升约 +5 dB（中性基准）
- 100 Hz 以下斜率约 -6 dB/oct（开放背板泄漏）
- 0.02% THD 在 1Vrms 输入下保持；过载（> 2Vrms）会快速恶化

### 典型使用场景

- 室内大耳放（需驱动电压 ≥ 200mW @ 300Ω）
- 推荐 24bit/96kHz Hi-Res 内容（51kHz 延伸需要）
- 不适合通勤（开放式几乎无隔音）

### 典型调音目标

- 6-7 kHz 窄带收敛（修 6.5k 锐利感）
- 100 Hz 以下平台补偿（+5dB 修正低频滚降）
- 12.5-20 kHz 微抬（Hi-Res 内容，设备 hi_res_capable）
- 110 Hz 段视前端特性微调（650Ω 谐振峰会与某些耳放发生自然抬升）

- **What Hi-Fi 直指痛点**：
  - "Recessed vocals"（人声靠后，不抓人）

### 典型使用场景

- 室内监听（有线模式可被手机直推 24Ω/98dB）
- LDAC 990kbps 高码率 BT 传输（推荐）
- **不推荐户外通勤**（全包裹设计权衡）

### 典型调音目标

- 1-2 kHz 人声核心区 +1.5dB（推前 "Recessed vocals"）
- 2 kHz 上缘 +1.0dB（人声胸腔/口型感）
- 5 kHz +0.5dB（乐器泛音，防齿音）
- 12.5-20 kHz 视 BT 模式微调（有线 / LDAC / SBC 模式不同）

### 测量数据（RTINGS）

- **频响一致性**：优秀（罩耳式密封保证单元与耳廓稳定耦合）
- **低频轻微抬升**：ANC 开启时 sub-bass 主动抬升（声学掩蔽对冲策略） 【测量】RTINGS
- **中高频略收**：Bose 商业目标曲线"Veiled"特征
- **>10 kHz 主动滚降**：封闭式物理衰减 + Bose 调音取舍
- **隔离性能**：优秀（ANC + 物理被动密封）

### 主观听感评价

- **"Veiled" 痛点**：高频被滚降遮蔽，镲片/齿音的空气感与细节不足 【用户】知乎深度评测 / RTINGS
- **"Muddy bass"** ANC OFF 时低频偏糊（ANC ON 时反受益）
- **"Lack detail"**：与 HiFi 玩家设备对比细节不足
- **"声场偏窄"**：封闭式 + ANC 物理上限，**EQ 不可改善**
- **降噪等级属硬件能力**：EQ 不可改变降噪深度

### 典型使用场景

- 通勤 / 办公 / 长时间佩戴（240g 轻量 + 24h 续航）
- 关闭 Bose App 内置 EQ（避免与 Poweramp 双 EQ 叠加失真）
- ANC ON/OFF 需分别校准（ANC 改变低频感知）

### 典型调音目标

- 40 Hz -1dB（收 ANC 偏多的 sub-bass）
- 2.5 kHz +1.5dB（人声可懂度核心，ANC 噪声掩蔽下收益最大）
- 8 kHz +1dB（补回 "Veiled" 起始段）
- 14 kHz +0.5dB（封闭式物理极限内的空气感恢复）
- **不可改善**：声场宽度、降噪等级
